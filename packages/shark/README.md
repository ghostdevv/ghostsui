# @ghostsui/shark

A simple cli to turn markdown into html

## `build`

```bash
Description
  Export markdown files as html

Usage
  $ shark build [input] [options]

Options
  -d, --out-dir    Output directory  (default dist)
  --watch          Watch for changes  (default false)
  --base           Asset base path  (default /)
  -h, --help       Displays this message
```
